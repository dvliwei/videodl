# VideoDL MVP 产品与技术说明

## 1. 产品目标

为 Windows、macOS、Linux 用户提供一个桌面视频下载器。用户粘贴网页 URL、点击“分析”，从识别出的媒体资源中选择一个或多个视频，选择保存位置后启动下载。应用展示可识别的分辨率、格式、时长、音视频轨道和大小信息，并提供可理解的任务进度与失败反馈。

核心体验：

```text
粘贴网页 URL → 分析资源 → 选择视频/清晰度 → 选择保存位置 → 下载/合并/可选转码 → 打开文件
```

## 2. MVP 范围

### 包含

- 分析无需登录、可公开访问且非 DRM 保护的 HTTP/HTTPS 网页。
- 识别网页中可直接获取的媒体 URL，以及可识别的 HLS (`.m3u8`) 和 MPEG-DASH (`.mpd`) 清单。
- 对 HTML 中的常见媒体元素和公开媒体清单进行解析；使用 FFprobe 检测媒体流信息。对依赖复杂 JavaScript、浏览器登录会话或站点专用接口的页面，允许返回“不支持/未发现可下载资源”，不承诺任意网站兼容。
- 结果展示标题/文件名、脱敏来源地址、分辨率、容器/协议、时长、音视频轨道、预估文件大小（未知时明确显示未知）。来源地址隐藏 query 和 fragment，实际下载地址由后端分析会话持有。标示信息来源或未知字段，避免把推测值伪装成准确值。
- 用户可选择单个资源下载；任务管理接口与 UI 支持多个任务，但并发数受限并可配置为合理的固定默认值。
- 首次下载或用户主动更改时选择默认下载目录。每个任务可“另存为”；同名文件提供覆盖、自动改名和取消选择。
- 下载任务显示准备、下载、合并/封装、转码、完成、取消、失败状态，以及可用的速度和进度信息；支持取消和失败后重试。暂停/续传不列入首版保证能力。
- 随应用包提供匹配目标平台的 FFmpeg 与 FFprobe，运行时无需用户单独安装或联网下载媒体工具。
- 支持原质量下载及无损封装；提供有限的兼容性转码预设，例如 MP4 (H.264/AAC)。转码需要用户主动选择，界面提示会增加耗时并可能有质量损失。
- 完成后可打开文件或所在目录。

### 不包含

- DRM 解密、绕过付费墙/访问控制、自动登录或提取浏览器登录凭据。
- 对所有网站、所有加密/直播协议、所有动态播放器的兼容承诺。
- 任意 FFmpeg 参数编辑、专业剪辑、字幕编辑、播放列表/频道订阅。
- 首版保证暂停续传、分布式/云端下载或后台常驻服务。

## 3. 分析与下载行为

### URL 分析

1. 前端 trim 输入并检查 URL 结构；仅允许 `http` 和 `https`。
2. Go 分析器抓取网页和公开媒体清单，限制请求体大小、重定向次数、连接/总超时，并设置清晰的 User-Agent。
3. 对每个重定向目标和 DNS 解析地址执行公网地址校验，拒绝 loopback、私有、链路本地、组播及保留地址；防范重定向和 DNS rebinding 导致访问本机或内网服务。
4. 分析器从 HTML 常见媒体标签、Open Graph/常见公开媒体元数据和 HLS/DASH 清单提取候选资源。MVP 不执行任意网页脚本。
5. 对候选媒体调用随包 FFprobe 获取容器、时长、分辨率、流信息；探测失败时保留候选并标注未能识别，不让一个资源失败拖垮全部结果。
6. 对无结果、受限页面、网络错误和不支持协议返回可区分的用户提示。

### 下载、封装和转码

- 由 Go 创建和管理任务，启动 FFmpeg 子进程完成直接媒体下载、HLS/DASH 分片读取、音视频选择/合并与封装。
- 解析 FFmpeg 的机器可读进度输出更新任务进度；UI 不解析 FFmpeg 日志。
- 默认选择源质量/复制编码流，避免不必要的转码。用户选择转码预设后，使用预设固定映射参数；禁止前端传递任意命令行字符串。
- 下载写入目标目录内的唯一临时文件。FFmpeg 成功退出且输出校验通过后，再将临时文件原子改名为最终文件。
- 取消必须终止对应进程并回收句柄；失败时报告可恢复/不可恢复原因，重试创建新尝试并避免覆盖有效文件。
- 任何平台上的 FFmpeg/FFprobe 都由应用资源解析器定位；不回退到 PATH 中的系统版本。

## 4. 主要界面

1. **分析页**：URL 输入框、分析按钮、取消分析、状态和错误提示。
2. **资源列表**：每个资源一行/卡片，显示标题、分辨率、格式、时长、大小、音频信息、选择状态和下载操作；支持按清晰度/格式排序。分析结果为空时说明原因及支持边界。
3. **下载任务区**：任务名、目标质量、阶段、进度、速度（可用时）、目标文件、取消、重试、打开文件/目录。
4. **保存位置**：默认目录设置、单任务“另存为”及重名处理。路径选择使用 Wails 原生对话框。

界面状态至少包含空闲、分析中、分析成功、分析无结果、分析失败、下载中、合并/封装中、转码中、完成、取消和失败。

## 5. 架构与接口责任

- **Vue 3**：表单、资源列表、任务列表和用户提示；维护展示状态，不承担媒体网络请求和文件写入。
- **Wails App API**：小而稳定的调用面，包括分析 URL、启动下载、取消任务、设置默认目录和选择输出文件/目录。返回结构化结果，不返回原始 FFmpeg 日志。
- **分析层 (Go)**：URL 校验、安全请求、HTML/清单解析、候选去重、媒体探测。网络和解析逻辑不依赖 Wails。
- **任务层 (Go)**：任务状态机、并发限制、重试/取消、进度解析、临时文件与最终文件发布。
- **媒体工具层 (Go)**：FFmpeg/FFprobe 路径解析、版本检测、参数构造、子进程生命周期及错误分类。
- **资源打包层**：在目标平台构建时将对应工具二进制和许可证放入应用资源；应用安装后离线可运行。
- **事件**：通过 Wails 事件向前端推送任务状态/进度，事件负载包含稳定的 task ID、状态、阶段、百分比（未知可为空）、速度（未知可为空）和用户可读错误。

目录职责、当前骨架状态和 API 契约见 `docs/ARCHITECTURE.md`。领域模型、分析器、任务管理器和工具执行器应可独立测试；业务包不依赖 Wails runtime。

## 6. FFmpeg 分发要求

- 首发发布矩阵：Windows x86_64、macOS x86_64/ARM64、Linux x86_64。Linux ARM64 可在首发后扩展，除非实际构建/测试能力验证后纳入。
- 当前固定版本为 FFmpeg 8.0.3，构建发行标签为 `ffmpeg-8.0.3-build4`，来源、四个平台归档 SHA-256、配置审计链接和编码器集合见 `build/resources/ffmpeg/manifest.yaml`。
- 当前发行构建使用 `--disable-gpl`、`--disable-nonfree`、`--disable-version3` 和 `--disable-autodetect`，按 LGPL-2.1-or-later 和相应第三方许可证发布；不包含 x264、x265 或 FDK-AAC。
- 每个平台均需提供匹配架构的 FFmpeg 和 FFprobe。应用启动/首次任务时检查工具可用性与预期版本；不能执行时显示可操作错误。
- 构建脚本必须在解压前校验固定归档 SHA-256，解压后为输入二进制生成并校验 `SHA256SUMS`；运行时不下载媒体工具，也不回退到 PATH。
- 发布包附带 `CREDITS.md`、FFmpeg LGPL 文本、第三方通知、上游源码/签名链接和每个平台配置审计材料。
- 维护者在发布前确认独立子进程分发模式、LGPL/第三方许可证义务以及编解码器专利事项；许可证状态不得留作未决事项。
- macOS 发布还需验证签名/公证与嵌套可执行文件；Windows 验证安装包文件布局和可执行权限；Linux 验证目标发行版运行依赖与可执行权限。

## 7. 非功能要求

- 分析网络请求必须有大小、重定向、连接和总时长上限，避免输入任意 URL 后无界消耗资源。
- FFmpeg 参数使用参数数组传递；不得经 shell 拼接。下载并发有上限，所有 goroutine/进程可随应用关闭正确结束。
- 不持久化媒体 URL 中不必要的认证/签名信息；日志脱敏。
- 任务状态和错误应结构化，前端可在不解析日志的情况下显示进度和可操作反馈。
- 关键状态转换、取消、重名、临时文件发布和错误分类均有可自动验证的测试。
- 大文件处理不把文件整体读入内存；文件写入使用流式处理或 FFmpeg 输出。

## 8. 发布验收

- 三个目标操作系统的构建包均包含正确架构的 FFmpeg/FFprobe，并能在无系统 FFmpeg 的干净环境中完成工具版本检测。
- 直接 MP4/WebM、HLS 分片和可识别的 DASH 示例可分析并完成下载/封装；测试素材来源须获授权或自行生成。
- 至少覆盖无结果、无效 URL、超时、重定向到非公网地址、FFprobe 失败、FFmpeg 非零退出、取消、重名与转码失败。
- 转码预设生成预期格式和音视频流，原质量模式不触发重新编码。
- 成功任务只发布完整最终文件；取消/失败不会留下误报完成的文件。
- 发布文档说明支持范围、已知限制、FFmpeg 版本/许可、支持的操作系统/架构和问题反馈方式。
