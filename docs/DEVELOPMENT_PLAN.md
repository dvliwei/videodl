# VideoDL MVP 开发计划

> **执行说明：** 实施者应先阅读本计划和 `docs/PRODUCT_SPEC.md`，再按任务顺序逐项完成。每项任务先编写/更新该任务的测试，再实现最小改动并运行对应验证。任务之间可在接口稳定后并行，但不得越过依赖任务。

**目标：** 交付一个 Windows、macOS、Linux 桌面视频下载器，用户可分析公开网页媒体资源，选择输出位置并下载、合并或按预设转码；FFmpeg/FFprobe 随应用分发。

**架构：** Go 提供 URL 分析、任务管理、跨平台文件/进程能力和 Wails API；FFmpeg/FFprobe 负责媒体探测、分片处理、合并、封装及可选转码；Vue 通过 Wails 调用和事件展示结果。工具二进制在构建/发布时进入对应平台应用包，运行时不要求单独安装。

**技术栈：** Go 1.25（当前 `go.mod`）、Wails v2.16（当前 `go.mod`）、Vue 3、Vite 7、随包 FFmpeg/FFprobe。

**产品说明：** `docs/PRODUCT_SPEC.md`

**架构说明：** `docs/ARCHITECTURE.md`  
**TRAE 使用说明：** `docs/TRAE_GUIDE.md`

## 全局约束

- 首发目标：Windows x86_64、macOS x86_64/ARM64、Linux x86_64。
- 仅支持公开、无需登录、非 DRM 的 HTTP/HTTPS 网页和可识别媒体资源。
- 所有网页请求和重定向目标都必须通过公网地址校验；限制请求体、重定向数、连接和总超时。
- FFmpeg/FFprobe 必须随安装包分发；运行时不依赖 PATH，也不联网下载工具。
- FFmpeg 子进程使用参数数组启动，不经 shell；支持取消、退出码检查、资源回收和有限并发。
- 默认复制源流并无损封装；重编码必须由用户选择固定转码预设触发。
- 最终文件只能在任务成功并校验后从临时文件发布；重名必须由用户决策或采用安全的自动改名策略。
- 不实现 DRM 解密、登录凭据提取、付费/访问控制绕过或任意 FFmpeg 参数输入。

## 重点审查场景

- 重定向或 DNS 解析指向本机/内网：请求应在访问目标前拒绝。
- URL 含用户信息、非法 scheme、IPv6、端口或恶意路径：校验稳定失败，不触发本地文件或 shell 操作。
- 网页/清单部分解析失败或某个候选无法探测：其余候选仍能展示，失败项标注原因。
- FFmpeg 输出没有总时长/无法计算百分比：任务仍显示阶段和可用进度，不出现 NaN 或错误的 100%。
- 用户在启动、下载、封装、转码阶段取消或应用关闭：子进程结束，临时文件和任务状态一致。

## 建议任务顺序

顺序按依赖和可交付闭环排列，不表示工期。所有验证都使用获授权或自行生成的媒体样本；真实目标网站只用于经许可的兼容性抽查。

## 目标文件布局

按任务逐步创建，不提前生成空包：

```text
app.go                              # Wails 门面和生命周期
main.go                             # Wails 启动与资源嵌入
internal/media/model.go             # Wails/业务共享模型（已建立）
internal/analyzer/                  # URL 请求、HTML/HLS/DASH 分析
internal/download/                  # 任务管理、进度、输出发布
internal/ffmpeg/                    # FFmpeg/FFprobe 定位与进程封装
internal/settings/                  # 默认下载目录与应用设置
frontend/src/features/analyze/      # URL 输入与资源结果
frontend/src/features/downloads/    # 下载任务 UI
frontend/src/shared/                # Wails API 和通用前端类型/UI
build/resources/ffmpeg/             # 各平台 FFmpeg/FFprobe 及许可清单
```

根包仅保留 Wails 适配；业务包不得导入 Wails runtime。跨模块的 JSON 数据结构和枚举集中在 `internal/media/model.go`。完整模块职责和目标 API 见 `docs/ARCHITECTURE.md`。

### 阶段 1：工程基线与领域模型

#### 任务 1：确定目录边界与工程基线

**交付：** 建立 Go 内部包/前端目录约定；保留 Wails 启动入口简洁；移除模板问候 API 和示例组件，使用标明未接入状态的产品页面骨架；明确本地开发、前端构建、桌面构建命令及平台先决条件。

**验收：** 空白应用可启动；前端生产构建和当前主机 Wails 构建成功；文档命令与项目配置一致。

#### 任务 2：定义媒体资源、分析结果和任务状态模型

**交付：** 在 `internal/media/model.go` 定义候选媒体、清晰度变体、分析结果、下载请求、任务状态和进度；定义 Wails API 返回结构与事件负载；错误码随对应服务任务定义。

**验收：** Go JSON 字段名与 `model.go` 标签一致；可空数值在未知时保持为空；前端调用/事件负载引用同一契约。任务状态迁移测试归入任务 11，避免把状态机实现提前塞入数据模型。

#### 任务 3：实现跨平台设置与路径服务

**交付：** 默认下载目录读取/保存、目录存在性/可写性检查、文件名清理、重名策略和唯一临时文件路径。平台专属路径使用 Go/Wails 系统目录能力，不硬编码用户目录。

**验收：** 覆盖 Windows 保留字符/名称、macOS/Linux 路径分隔、Unicode 文件名、空文件名、重名和不可写目录；单元测试不访问真实用户目录。

### 阶段 2：媒体工具随包与探测

#### 任务 4：锁定 FFmpeg/FFprobe 发行来源和许可

**状态：已完成（来源、哈希、配置审计链接和发布许可材料已锁定；平台资源接入仍属于任务 18）。**

**交付：** 选择固定版本、每个平台构建来源和编码器集合；记录来源、SHA-256、许可证、配置与源码提供方式；将适用许可证纳入发布材料。

**验收：** 维护者确认分发许可与源码义务；目标平台和架构的工具清单完整；构建流程校验下载/输入二进制哈希，不在运行时下载。

#### 任务 5：实现媒体工具定位、版本检查和进程包装

**交付：** Go 工具层解析应用资源中的 FFmpeg/FFprobe，校验可执行与版本，使用参数数组启动进程，统一捕获退出码、取消、超时、标准输出/错误和清理行为。

**验收：** 找不到工具、版本错误、非零退出、输出过大、超时和取消均返回结构化错误；不会调用 PATH 回退或 shell。

#### 任务 6：实现 FFprobe 媒体信息探测

**交付：** 将 FFprobe JSON 输出映射为分辨率、时长、容器/编解码器、音视频流、帧率及可获得的大小信息；缺失字段使用空值/未知表示。

**验收：** 使用自制 MP4、WebM、HLS/DASH 小样本覆盖多流、纯音频、无时长、损坏媒体及探测超时；解析失败不崩溃。

### 阶段 3：网页与媒体清单分析

#### 任务 7：实现 URL 校验和安全网页抓取

**交付：** HTTP/HTTPS URL 校验、超时和响应体上限、有限重定向、安全 DNS/IP 检查、请求头策略和敏感信息脱敏。

**验收：** 单测拒绝 loopback、私有、链路本地、保留地址、重定向到非公网地址及非法 scheme；覆盖 IPv4/IPv6 和 DNS 多地址；验证校验发生在连接目标前。

#### 任务 8：实现静态 HTML 媒体提取

**交付：** 解析 `<video>`、`<source>`、常见公开媒体元数据和页面标题；相对 URL 按网页基址解析；候选规范化与去重；明确不执行任意 JavaScript。

**验收：** fixture 覆盖单/多个资源、相对路径、重复地址、无媒体、畸形 HTML、非 HTML、错误响应和受限页面。

#### 任务 9：实现 HLS/DASH 资源识别与变体列举

**交付：** 识别 HLS/DASH 清单及可访问变体，列出可选清晰度/带宽/音视频组合；把需要的请求头上下文安全传给任务层。DRM 或需要授权解密的资源应识别为不支持，不尝试绕过。

**验收：** fixture 覆盖多清晰度 HLS、音视频分离 HLS、DASH 多 Representation、相对分片地址、无效清单和 DRM 标志；无法识别时给出原因。

#### 任务 10：组合分析服务

**交付：** 编排安全抓取、HTML/清单提取、候选去重和 FFprobe 探测；单候选失败不影响其他结果；分析支持 context 取消。

**验收：** 集成测试覆盖有效网页、直接媒体 URL、HLS、DASH、空结果、网络失败、探测失败、超时和取消；返回结果字段完整且稳定。

### 阶段 4：下载任务闭环

#### 任务 11：实现任务管理器和并发控制

**交付：** 创建/读取/取消/重试任务，限制活跃任务数，记录尝试次数与阶段；每个任务拥有独立 context、进程和临时输出。

**验收：** 测试重复取消、重复重试、并发上限、任务状态事件顺序和应用关闭时清理；取消一个任务不影响其他任务。

#### 任务 12：实现 FFmpeg 下载、封装和进度解析

**交付：** 以 FFmpeg 处理直链/HLS/DASH 输入，固定参数选择流并执行复制封装；解析机器可读进度；处理 Referer 等必要请求上下文，不在 UI 暴露命令行。

**验收：** 授权样本完成直链、HLS 分片、DASH 音视频合并；无总时长时不伪造百分比；非零退出、网络中断、取消不会发布最终文件。

#### 任务 13：实现文件发布、重名与重试

**交付：** 输出到目标目录临时文件，成功校验后原子改名；重名通过覆盖/自动改名/取消处理；失败重试使用新尝试与安全临时文件。

**验收：** 覆盖成功发布、目标文件已存在、改名、取消覆盖选择、磁盘写入失败、残留临时文件和失败后重试；已有完整文件不会被误删。

#### 任务 14：实现固定转码预设

**交付：** 至少提供“原始质量/无损封装”和“兼容 MP4 (H.264/AAC)”两种选择；转码参数由后端预设映射，UI 不传原始命令参数。

**验收：** 原始模式确认使用 stream copy；转码样本生成可探测 MP4；取消/失败处理正确；界面提示转码耗时和可能的质量损失。

### 阶段 5：Wails 接口与用户界面

#### 任务 15：接入 Wails API、目录对话框和事件

**交付：** 绑定分析、开始下载、取消/重试、默认目录和“另存为”能力；任务状态通过有版本约定的 Wails 事件推送；应用退出时停止任务。

**验收：** 前端可调用成功和错误返回；事件包含 task ID 且不重复绑定；原生文件对话框取消不会创建任务。

#### 任务 16：实现 URL 输入与分析结果界面

**交付：** 输入框粘贴/回车分析、格式校验、取消分析、加载/空结果/失败状态；资源卡片显示标题、分辨率、格式、时长、大小、音频信息和下载操作。

**验收：** 鼠标与键盘均可完成分析；未知字段清楚标示；窄窗口和长文件名不破坏布局；无结果提示支持范围。

#### 任务 17：实现保存位置与任务列表界面

**交付：** 首次设置默认目录、任务另存为、重名决策、下载任务阶段/进度/速度、取消、重试和完成后的打开文件/目录。

**验收：** 状态映射与后端一致；未知进度不显示错误百分比；多个任务区分清晰；文件对话框取消/失败可恢复。

### 阶段 6：跨平台打包与发布

#### 任务 18：接入平台资源布局和构建产物

**交付：** 根据 GOOS/GOARCH 选择对应 FFmpeg/FFprobe 并纳入 Wails 包；发布材料包含许可证和版本清单；开发和发布构建路径可重复。

**验收：** 各平台安装包检查工具路径、架构、可执行权限、SHA-256 和许可证；安装后断网且机器未安装 FFmpeg 时可完成版本检测。

#### 任务 19：执行平台验收与发布收尾

**状态：部分完成（macOS ARM64 已验证；Windows/Linux 需在对应平台构建；正式签名/公证需证书）。**

**交付：** 完成三个首发目标系统的构建/冒烟检查，覆盖安全拒绝、下载、合并、取消、重试、重名和转码；更新 README 的安装、支持范围和限制。

**验收：** 发布清单逐项通过；macOS 签名/公证、Windows 安装器和 Linux 运行依赖有对应验证记录；不支持场景与 FFmpeg 许可说明随包可查。
